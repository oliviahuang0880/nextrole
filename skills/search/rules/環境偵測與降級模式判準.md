# 環境偵測與降級模式判準

每次啟動 skill 的第一件事就是判斷這台機器能不能跑爬蟲。

# Rule 1 - 用 `command -v uv` 判斷模式

- Level: `MUST`

| 偵測結果 | 模式 | 行為 |
|---|---|---|
| 有 `uv` | 完整模式 | 走 Phase 1–5，跑爬蟲 |
| 沒 `uv` 但有 bash | 詢問後決定 | 同意安裝 → 完整模式；不同意 → 降級模式 |
| 完全沒有 bash（claude.ai 網頁／桌面 app） | 降級模式 | 只用對話跑問卷 |

# Rule 2 - 安裝 uv 必須先問過使用者

- Level: `MUST`
- 不得未經同意就跑安裝指令。問法：

```text
我可以幫你裝 uv 嗎？這是個免費工具，會幫你跑 Python 腳本，一行指令裝完：
curl -LsSf https://astral.sh/uv/install.sh | sh
同意嗎？
```

# Rule 3 - 降級模式的替代路徑

- Level: `MUST`
- Phase 3 技能問卷：直接讀 `references/method2_skills.json` 用純對話跑，一樣遵守 `rules/技能問卷對話節奏判準.md`。
- Phase 3 收尾：不能跑 `build_profile.py`，改成把 classifications／notes 整理成關鍵字清單直接給使用者，並依 `templates/keywords-report.md` 呈現。
- Phase 5 搜尋：不能跑爬蟲，改輸出三個站的搜尋網址清單讓使用者貼到瀏覽器（完整模式下這份清單由 `browser_urls.py` 產生）。
- 降級模式要明講：「這台機器不能跑爬蟲，所以我給你搜尋網址，你自己開來看」，不要假裝有跑。

# Rule 4 - 不需要 ANTHROPIC_API_KEY

- Level: `MUST`
- 彙整朋友描述、抽 JD 關鍵字、判斷使用者的文字回答屬於哪一類 — 全部由**你（正在對話的 agent）**直接做。
- 不得呼叫任何外部 AI API，也不得要求使用者提供 API key。
