# 求職信結構

這裡說的求職信是**投遞平台上的投遞訊息**（104 的投遞訊息這類），不是正式書信。
不要用「敬啟者」「耑此敬頌」這種罐頭格式，就是口語地跟人說話。

## 寫之前

1. 先做完**契合度診斷**（`/nextrole:board` Phase 1）。投不投是那裡決定的，不是這裡。
2. 先判斷該配哪一版履歷（見 `rules/履歷版本判斷.md`）。
3. 先載入 `rules/去AI味檢查.md`，**一開始就照著寫，不是事後洗**。

## 核心要回答三件事

1. 我為什麼是適合的人選
2. 我過去的經驗能為這份工作帶來什麼貢獻
3. **為什麼他們非跟我聊不可**

第 3 點最常被漏掉。前兩點回答「我可以」，第 3 點才回答「為什麼是我不是別人」。

## 固定四段

**① 開場：我是誰**
一句定位，直接說擅長什麼，把定位接到這份工作的核心。
⛔ 不要複述職缺描述（「看到你們在找…」那段把 JD 抄一遍）。那是他們寫的，他們知道。

**② 核心能力＋具體戰績**
一句話講最核心的能力，接兩到三個具體成果。數字只能取自素材庫，不能生。
挑 **JD 明寫要的**那幾個，不要貪多。

**③ 動機**
從「這件事我一直在做、也喜歡做」切入，讓戰績自己證明可勝任。

⛔ **不主動提缺口。** JD 標「尤佳／加分」而使用者沒有的一律不寫。主動說「我沒有 X」
等於替對方放大一個他原本沒在意的問題，而那幾行本來能拿去講戰績。

⭐ **唯一例外**：該條件被列為**必要**、而且對方看履歷就會發現（必備年資、必備產業實戰），
才用**一句話**帶過並立刻轉回可遷移能力。不另闢一段，不解釋、不道歉。

**④ 結尾：我喜歡這裡的什麼**
先說出**具體**喜歡哪一點，再收「期待和你們聊聊」。引完接一句自己為何被打動、
跟自己做事方式的連結。

引用的來源，依序：

1. **JD 本身**。職責清單裡某一條、或他們描述團隊與工作方式的句子。這就夠了。
2. **公司介紹／官網文化頁**的具體一句。
3. 已經跑過 `/nextrole:interview` 的「準備一家公司」→ 直接用那邊研究出來的東西。

⛔ **不要為了寫求職信另外做一輪公司研究。** 深入挖產品頁、定價頁、近期新聞是
**面試準備**的工作，不是投遞當下的工作。投遞要快，卡在二十分鐘的研究上，
等於每投一家都先做一次面試準備。

## 字數

目標帶讀 `config.json` 的 `cover_letter_max_chars`（預設 300），實際抓 **目標值到 +50**。

⚠️ **上限不是硬的，不要自己先砍。** JD 命中點多的時候，硬壓到目標值會把最有力的實例砍掉。
做法是：

1. 先寫**完整版**。
2. 回報字數，並指出「要壓到 <目標值> 的話該砍哪一段、代價是什麼」。
3. **讓使用者決定**砍不砍。

超過**目標值 +100** 就一定要主動壓，那時候是真的太長了。

## 預設不複述履歷

假設對方已經看過履歷。篇幅留給履歷沒講的：角色連結、動機、reframe。

**但這不是硬規則**：如果某個戰績數字剛好正面命中 JD 的核心需求，帶進來更有說服力就帶。
原則是「沒有特別理由就不寫；有理由能加分才破例」。

## 寫完的檢查

| 檢查 | 判準 |
|---|---|
| 把公司名換成競爭對手，這封信還成立嗎？ | **成立就是零分，重寫。**第 ④ 段沒有引到具體的東西時最常發生 |
| 第 ④ 段引的東西，具體嗎？ | 「貴公司很有前景」「認同貴公司的企業文化」＝空泛。要引得出是哪一句 |
| 第 ③ 段講的是「我想要」還是「我們為什麼合」？ | 「我想學更多／想有更好的發展」＝零分 |
| 三件事都回答了嗎？ | 特別是第 3 件：為什麼他們非跟我聊不可 |
| 字數 | 超過目標值就回報取捨，不要自己砍 |
| 去 AI 味 | 對照 `去AI味檢查.md` 走一遍，特別搜 `—` 與 `——` |

## 三種常見錯法

| ⛔ | ⭕ |
|---|---|
| 只講公司好（「規模數一數二、制度完整」） | 講**他們在做什麼**，不是他們有多大 |
| 只講自己想要（「我想學更多」） | 把「我想要」翻譯成「**我們為什麼合**」：我做過 A 但碰不到 B，這個職位剛好補得上 |
| 太籠統（「我認同貴公司的企業文化」） | 引 JD 上的具體職責 ＋ 我剛好處理過的類似狀況 |

💡 動機不高尚不是問題（離家近、薪水好）。**只講到那裡就停才是問題。**
接法＝「通勤短，我可以把精力放在工作上」＋ 一句你對這個職位的理解。
