# 求職信結構

這裡說的求職信是**投遞平台上的投遞訊息**，不是正式書信。
不要用「敬啟者」「耑此敬頌」這種罐頭格式，就是口語地跟人說話。

字數上限讀 `config.json` 的 `cover_letter_max_chars`（預設 300 字）。
**上限是硬的** — 超過就砍，不要求情。

## 核心要回答三件事

1. 我為什麼是適合的人選
2. 我過去的經驗能為這份工作帶來什麼
3. 為什麼他們非跟我聊不可

## 固定四段

**① 開場：我是誰**
一句定位，直接說擅長什麼，把定位接到這份工作的核心。
⛔ 不要複述職缺描述（「看到你們在找…」那段把 JD 抄一遍）— 那是他們寫的，他們知道。

**② 核心能力＋具體戰績**
一句話講最核心的能力，接兩到三個具體成果（含數字）。
挑 **JD 明寫要的**那幾個，不要貪多。

**③ 動機**
從「這件事我一直在做、也喜歡做」切入，讓戰績自己證明可勝任。
⛔ **不主動提缺口。** 信只有幾百字，那幾行本來能拿去講戰績。

**④ 結尾：我喜歡這裡的什麼**
先根據 JD 或公司介紹說出**具體**喜歡哪一點，再收「期待和你們聊聊」。
- 要引 JD、產品頁、公司介紹裡的**具體一句**，不能空泛講「貴公司很有前景」
- 引完接一句自己為何被打動、跟自己做事方式的連結

## 預設不複述履歷

假設對方已經看過履歷。篇幅留給履歷沒講的：角色連結、動機、reframe。

**但這不是硬規則**：如果某個戰績數字剛好正面命中 JD 的核心需求，帶進來更有說服力就帶。
原則是「沒有特別理由就不寫；有理由能加分才破例」。

## 寫完的檢查

| 檢查 | 判準 |
|---|---|
| 把公司名換成競爭對手，這封信還成立嗎？ | **成立就是零分，重寫。** |
| 第 ④ 段引的事實，JD 上有嗎？ | JD 上就有＝太淺。往產品頁／定價頁／官網挖只有他們有的具體事實 |
| 第 ③ 段講的是「我想要」還是「我們為什麼合」？ | 「我想學更多／想有更好的發展」＝零分 |
| 字數 | 超過上限就砍 |
| 去 AI 味 | 對照 `去AI味檢查.md` 走一遍 |

⭐ 第二項是差距最大的一項。花二十分鐘去產品頁、定價頁挖一個 JD 上沒有的具體事實，
就是跟海投的人的差別。

## 三種常見錯法

| ⛔ | ⭕ |
|---|---|
| 只講公司好（「規模數一數二、制度完整」） | 講**他們在做什麼**，不是他們有多大 |
| 只講自己想要（「我想學更多」） | 把「我想要」翻譯成「**我們為什麼合**」：我做過 A 但碰不到 B，這個職位剛好補得上 |
| 太籠統（「我認同貴公司的企業文化」） | 引 JD 上的具體職責 ＋ 我剛好處理過的類似狀況 |

💡 動機不高尚不是問題（離家近、薪水好）。**只講到那裡就停才是問題。**
接法＝「通勤短，我可以把精力放在工作上」＋ 一句你對這個職位的理解。
