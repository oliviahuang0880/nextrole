# 試算表格式規範

## 頁籤結構

| 頁籤 | 欄位 |
|---|---|
| **故事庫** | 故事名稱｜🎯 特質｜🏷️ Tag｜S/T/A/R 內容。最後留一列問題對照表（題型 → 用哪個故事） |
| **常見問題** | 四欄：類別｜面試問題｜回答重點·腳本｜地雷·備註 |
| **每家公司一個頁籤** | 三欄：類別｜面試問題／項目｜回答重點·腳本（可直接照唸） |

## 公司頁籤的列標

第一欄用固定的語意標籤，這樣一眼掃得到要找的東西：

| 標籤 | 放什麼 |
|---|---|
| 🔑 這場的定位 | 這份 JD 的異常之處推論出來的姿態，一句話 |
| 🔑 發現 ①②③ | 兩到三個關鍵洞察 |
| 📖 產品實況 | 白話版的產品理解，要能自己複述 |
| 🏢 文化重點 | 只寫制度，不寫價值觀 |
| 🎤 自我介紹 | 客製化版本 |
| 🎤 必考題 | 預測題＋用哪個故事 |
| 💪 優勢 | 對這家的三個賣點 |
| 🕳 缺口 | JD 要而使用者沒有的，附誠實答法 |
| 🚨 地雷 | 這場不能講的 |
| ⚠️ 只有你能準備 | 需要他自己去查或想的（產品試用、個人經驗） |
| ❓ 反問 | 3–4 個 |
| 💰 薪資 | 期望帶與反問句 |
| 🔥 開場提問 | 一進門可以先問的 |

復盤時在最後加分隔列 `— 復盤 YYYY/MM/DD —`，之後接復盤內容。

## 格式（不可省）

1. **先 `read_sheet_values` 讀現況**，別覆蓋使用者的手改。
2. `modify_sheet_values` 寫入。
3. `format_sheet_range` 套格式：
   - 標題列：粗體 ＋ 背景 `#D9E1F2`
   - A 欄整欄粗體
   - 資料範圍：`wrap_strategy=WRAP`、`vertical_alignment=TOP`

⚠️ **`WRAP` ＋ `TOP` 不設的話，長文字會擠成一行，等於看不到。**
這是最常漏掉、後果最明顯的一項。

## 效率

改動一次講完、批次寫入、避免重排整塊。錯字使用者自己修，不要為了一個字重寫整列。
